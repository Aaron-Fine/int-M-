# Phase 1 color and non-color evidence — `4fd4fdd`

## Implemented encodings

| State or view       | Color treatment           | Non-color treatment                                |
| ------------------- | ------------------------- | -------------------------------------------------- |
| Stability           | Neutral grayscale         | Lightness directly represents intrinsic stability  |
| Multiplier          | Angle-driven hue          | Oriented lightness stripes encode multiplier angle |
| Period              | Distinct period hues      | Legend labels and shape-coded catalog markers      |
| Escaped             | Dark grayscale/blue range | Dashed legend border                               |
| Unresolved          | Neutral gray              | Diagonal texture and dotted legend border          |
| Selected point      | White/accent treatment    | Persistent ring and crosshair                      |
| Catalog periods 1–4 | Accent fill               | Circle, rounded square, triangle, and diamond      |
| Forced colors       | System colors             | 3 px focus outline and selected-point outline      |

The principal light-theme interface tokens are page `#f4f5f2`, surface
`#ffffff`, ink `#17201c`, muted ink `#5d6862`, accent `#d75b36`, strong accent
`#a83c1f`, and focus `#1867c0`. A complete dark palette and forced-colors rules
are declared in `src/styles.css`.

Unit tests verify neutral unresolved output, escaped/unresolved separation,
stability grayscale, multiplier hue, oriented multiplier lightness stripes,
and unresolved raster texture. Browser tests verify shape-coded catalog
markers, the selected ring/crosshair, and system-color focus/state cues.
